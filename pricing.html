Questions

Which assets are in the current release?

The current workspace is operated on Arc Testnet. In-product availability and the relevant payment path determine which supported token is used.

Does Agent Evidence add a payment fee or execute a payment?

Agent Evidence analyzes and records a decision trail. It does not approve, submit, or execute a payment.

Is Mainnet live through this public page?

No. The public site describes the current Arc Testnet release. Mainnet production release work is being finalized separately.
