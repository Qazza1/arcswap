Payments

Exact, invoice-bound payer flow.

A payer sees the backend-authoritative invoice terms. When needed, their wallet prompts for a precise USDC approval and an explicit payment transaction.

  • No unlimited token approval
  • No arbitrary recipient or contract selection
  • Settlement remains monitor-authoritative

Security

Wallet ownership without password accounts.

ArcFX uses the selected EIP-6963 wallet provider and a short-lived, browser-tab owner session for ordinary navigation. The session is not placed in a URL or handed between origins.

  • Explicit Mainnet switch action
  • Wallet/account uncertainty fails closed
  • Payment execution remains a separate wallet action
