API Reference

ArcFX Developer API

Programmatically create payments, send batch transfers, generate invoices, and query analytics on Arc. Built for businesses that need stablecoin infrastructure, not just a UI.

Base URL: https://api.arcfx.app/v1  ·  All requests over HTTPS  ·  Responses in JSON
Quick example
# Create a payment link and get back a shareable URL
curl -X POST https://api.arcfx.app/v1/payments/create \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient": "0x4F81E3939232815e3C98B124A17BaC75304C82D8",
    "amount": "250.00",
    "token": "USDC",
    "note": "Invoice #INV-2026-041"
  }'

# Response
{
  "id": "pay_3k9xmT2qR8Lv",
  "url": "https://arcfx.app/pay?to=0x4F81...&amount=250&token=USDC",
  "status": "pending",
  "created_at": "2026-05-23T09:41:00Z"
}
Authentication

API Keys

All API requests require a Bearer token in the Authorization header. Generate your API key from the ArcFX dashboard after subscribing.

Keep your API key secret. Never expose it in client-side code or public repositories.
Authorization header
Authorization: Bearer arcfx_live_sk_xxxxxxxxxxxxxxxxxxxx
Key prefixEnvironmentDescription
arcfx_live_sk_productionReal USDC on Arc Mainnet
arcfx_test_sk_testnetTest USDC on Arc Testnet
Payments

Create a payment

Generate a shareable pay link. The recipient receives net amount after the 0.15% protocol fee.

POST /v1/payments/create
Request body
ParameterTypeRequiredDescription
recipientstringrequiredWallet address that receives payment
amountstringrequiredAmount in token units (e.g. "250.00")
tokenstringrequired"USDC" or "EURC"
notestringoptionalReference note shown to payer
webhook_urlstringoptionalPOST endpoint for payment confirmation
Response
{
  "id":          "pay_3k9xmT2qR8Lv",
  "url":         "https://arcfx.app/pay?to=0x4F81...&amount=250&token=USDC&note=INV-041",
  "recipient":   "0x4F81E3939232815e3C98B124A17BaC75304C82D8",
  "amount":      "250.00",
  "fee":         "0.375",      // 0.15% of 250
  "net":         "249.625",
  "token":       "USDC",
  "status":      "pending",    // pending | paid | expired
  "created_at":  "2026-05-23T09:41:00Z"
}
GET /v1/payments/{id} Retrieve a payment by ID
Example
curl https://api.arcfx.app/v1/payments/pay_3k9xmT2qR8Lv \
  -H "Authorization: Bearer YOUR_API_KEY"
Multisend

Batch transfers

Send USDC or EURC to up to 500 wallets in a single on-chain transaction. Ideal for payroll, DAO distributions, and airdrops.

POST /v1/multisend
Request body
{
  "token":      "USDC",
  "recipients": [
    { "address": "0xABC...", "amount": "500.00" },
    { "address": "0xDEF...", "amount": "1250.00" },
    { "address": "0x123...", "amount": "750.00" }
  ],
  "memo":       "May 2026 payroll"  // optional
}
Response
{
  "batch_id":     "batch_7mNpQx9R",
  "tx_hash":      "0x02ab...17b4",
  "recipients":   3,
  "total_amount": "2500.00",
  "fee":          "3.75",           // 0.15% of total
  "status":       "confirmed",
  "explorer":     "https://testnet.arcscan.app/tx/0x02ab...17b4"
}
Invoices

Generate invoices

Programmatically create professional PDF invoices with an embedded Pay Now link. Returns a hosted PDF URL and a payment link.

POST /v1/invoices/create
Request body
{
  "from": { "name": "ArcFX Ltd", "wallet": "0x4F81..." },
  "to":   { "name": "Client Corp", "email": "ap@client.com" },
  "token": "USDC",
  "items": [
    { "description": "Smart contract audit", "qty": 1, "unit_price": 2500 },
    { "description": "Integration support",  "qty": 4, "unit_price": 150  }
  ],
  "due_date": "2026-06-01"
}
Response
{
  "invoice_id":  "inv_9bKpRm3xQ",
  "pdf_url":     "https://api.arcfx.app/v1/invoices/inv_9bKpRm3xQ/pdf",
  "pay_url":     "https://arcfx.app/pay?to=0x4F81...&amount=3100&token=USDC",
  "total":       "3100.00",
  "status":      "unpaid"   // unpaid | paid | overdue
}
Webhooks

Payment webhooks

Receive real-time notifications when a payment is confirmed on-chain. ArcFX listens to the PaymentExecuted contract event and POSTs to your endpoint within seconds.

POST /v1/webhooks/register
Register your endpoint
{
  "url":    "https://your-server.com/arcfx/webhook",
  "events": ["payment.confirmed", "multisend.confirmed"]
}
Webhook payload (sent to your server)
{
  "event":      "payment.confirmed",
  "payment_id": "pay_3k9xmT2qR8Lv",
  "tx_hash":    "0x02ab...17b4",
  "amount":     "250.00",
  "token":      "USDC",
  "payer":      "0xABC...",
  "recipient":  "0x4F81...",
  "block":      43571839,
  "timestamp":  "2026-05-23T09:43:17Z"
}
